# packdata

Pack structured JSON data payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/packdata/

## Install / run

```bash
git clone https://github.com/theworker02/packdata.git
cd packdata
node src/cli.js
node --test
```
